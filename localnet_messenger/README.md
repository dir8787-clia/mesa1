# LocalNet Messenger

**Локальный мессенджер для безопасного общения в вашей сети**

LocalNet Messenger — это полноценный графический мессенджер для локальной сети (LAN), который работает без доступа к интернету и не использует внешние облачные сервисы.

## Возможности

- ✅ **Регистрация и вход** — безопасная аутентификация с хешированием паролей (Argon2)
- ✅ **Обнаружение сервера** — автоматический поиск через mDNS/Zeroconf или ручное подключение
- ✅ **Личные чаты** — обмен сообщениями в реальном времени
- ✅ **Групповые чаты** — создание групп с несколькими участниками
- ✅ **Отправка файлов** — передача файлов любого типа
- ✅ **Индикатор набора** — показывается, когда пользователь печатает
- ✅ **Статусы сообщений** — отправлено, доставлено, прочитано
- ✅ **История сообщений** — сохраняется на сервере и локально
- ✅ **Присутствие** — онлайн/офлайн статусы пользователей
- ✅ **Уведомления** — системные уведомления о новых сообщениях
- ✅ **Темная/светлая тема** — современный интерфейс на PySide6/Qt
- ✅ **Работа в офлайне** — очередь сообщений при разрыве соединения
- ✅ **Автопереподключение** — восстановление связи после обрыва

```bash
cd localnet_messenger
pip install -r requirements.txt
```

## Запуск

### 1. Запуск сервера

Сервер можно запустить на любом компьютере в локальной сети:

```bash
python -m localnet_messenger.server.server --host 0.0.0.0 --port 8765
```

**Параметры:**
- `--host` — адрес для прослушивания (по умолчанию 0.0.0.0)
- `--port` — порт (по умолчанию 8765)
- `--data-dir` — директория для данных (по умолчанию ./server/data)

**Пример:**
```bash
python -m localnet_messenger.server.server --port 8765
```

### 2. Запуск клиента

Клиент запускается на компьютерах пользователей:

```bash
python -m localnet_messenger.client.client
```

При первом запуске:
1. Введите адрес сервера (или используйте автообнаружение)
2. Зарегистрируйтесь или войдите
3. Начните общение!

## Настройка фаервола

Для работы мессенджера необходимо открыть порт **8765 TCP** в фаерволе:

### Windows
```powershell
netsh advfirewall firewall add rule name="LocalNet Messenger" dir=in action=allow protocol=TCP localport=8765
```

### Linux (ufw)
```bash
sudo ufw allow 8765/tcp
```

### Linux (firewalld)
```bash
sudo firewall-cmd --add-port=8765/tcp --permanent
sudo firewall-cmd --reload
```

### macOS
```bash
sudo /usr/libexec/ApplicationFirewall/socketfilterfw --add /path/to/python
```

## Протокол обмена

Мессенджер использует JSON поверх WebSocket. Пример сообщения:

```json
{
  "version": "1.0",
  "type": "message.send",
  "id": "uuid-1234-5678",
  "timestamp": 1234567890.123,
  "sender": "user-id",
  "payload": {
    "chat_id": "chat-id",
    "content": "Привет!",
    "content_type": "text"
  },
  "token": "session-token"
}
```

### Типы сообщений

| Тип | Описание |
|-----|----------|
| `auth.register` | Регистрация пользователя |
| `auth.login` | Вход в систему |
| `auth.logout` | Выход из системы |
| `message.send` | Отправка сообщения |
| `message.history` | Запрос истории сообщений |
| `message.read` | Подтверждение прочтения |
| `chat.create` | Создание чата |
| `group.create` | Создание группы |
| `typing.start` | Начало набора текста |
| `typing.stop` | Окончание набора |
| `presence.status` | Статус присутствия |
| `heartbeat` | Проверка соединения |

## Безопасность

- **Хеширование паролей** — Argon2id для надежного хранения
- **Сессионные токены** — UUID для аутентификации
- **Валидация данных** — проверка всех входящих данных
- **Защита от path traversal** — безопасные пути к файлам
- **Ограничение размера** — лимиты на сообщения и файлы

## Хранение данных

Данные хранятся в SQLite:
- `users` — пользователи и хеши паролей
- `sessions` — активные сессии
- `chats` — чаты и группы
- `messages` — история сообщений
- `attachments` — метаданные файлов

Путь к базе данных: `./server/data/messenger.db`

## Устранение проблем

### Клиент не видит сервер
1. Убедитесь, что сервер запущен
2. Проверьте, что оба устройства в одной сети
3. Попробуйте подключиться по IP вручную
4. Проверьте фаервол

### Ошибка подключения
- Убедитесь, что порт 8765 открыт
- Проверьте логи сервера
- Перезапустите сервер

### Проблемы с GUI на Linux
```bash
# Установите зависимости
sudo apt-get install libegl1 libgl1 libxkbcommon0 libdbus-1-3
```
