### Обоснование выбора технологий

1. **Flask** - Легковесный фреймворк, идеально подходит для внутренних инструментов
   - Минимальные накладные расходы
   - Простая интеграция с расширениями
   - Хорошая документация

2. **SQLite** - Встроенная БД без необходимости отдельного сервера
   - Не требует обслуживания
   - Достаточно производительна для небольших/средних нагрузок
   - ACID-совместима

3. **Ansible** - Стандарт де-факто для управления инфраструктурой
   - Нативная поддержка Windows через WinRM
   - Идемпотентность операций
   - Богатый набор модулей для Windows

4. **APScheduler** - Планировщик задач внутри приложения
   - Поддержка cron-формата
   - Интеграция с Flask
   - Не требует внешних зависимостей

5. **Threading + subprocess** - Для фоновых задач
   - Простота реализации
   - Не требует message broker (как Celery)
   - Достаточно для умеренной нагрузки

6. **WinRM** - Протокол управления Windows
   - Встроен в Windows 10/11
   - Поддержка NTLM и Kerberos
   - Безопасное соединение
